# GitHub Showcase Checklist

Capture screenshots from the running application, not mockups.

Recommended sequence:
1. Market overview with the selected symbol and period visible.
2. Stock analytics metrics and historical chart.
3. Data Quality report with its score and validation counts.
4. Stock comparison table.
5. Watchlist with saved symbols.
6. AI Analyst question and response.
7. Downloaded Excel workbook showing its Price History, Data Quality, and Analytics Summary sheets.

Before committing screenshots:
- Hide personal account details and private file paths.
- Never show `.env` contents, access tokens, credentials, or database passwords.
- Use a consistent browser zoom and capture readable text.
- Only describe a section as working after testing it.
- Do not imply that historical values are live quotes.

Suggested README placement:

```markdown
## Screenshots

![Market overview](docs/screenshots/market-overview.png)
![Data quality report](docs/screenshots/data-quality.png)
![Stock comparison](docs/screenshots/stock-comparison.png)
```
